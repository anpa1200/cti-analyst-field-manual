# Contributing

This project accepts defensive, public, TLP:CLEAR improvements only.

## Contribution Rules

- Do not add malware source code, exploit instructions, leaked data, credentials, or victim-sensitive information.
- Separate reported facts, analyst assessment, inference, assumptions, and gaps.
- Use evidence labels: Observed, Reported, Assessed, Inferred, Unknown, Gap.
- Use confidence levels only when the confidence reason is documented.
- Do not force ATT&CK mappings or use ATT&CK as attribution evidence.
- Prefer practical templates, checklists, and workflows over vague prose.

## Review Checklist

- Does the page state its purpose?
- Are claims sourced or explicitly marked as placeholders?
- Are limitations documented?
- Are cross-links useful?
- Does the output help a CTI analyst produce a usable artifact?
